# Amdir Music Player

Програвач власної музики (MP3 / OGG) для World of Warcraft 3.3.5a.

- Грає навіть коли музика в налаштуваннях WoW **вимкнена**.
- **Не приглушується** голосовим чатом (звук іде через канал «Загальна гучність» / Master).
- Папки з піснями будь-якої вкладеності, випадковий порядок, автоматичний перехід на наступний трек.
- Власний повзунок гучності: решта звуків гри при цьому лишається такою ж гучною.
- Кнопка на мінімапі (ЛКМ — вікно, ПКМ — грати/стоп, тягни — перемістити).

## Як додати музику

Музика зберігається в окремій папці `Interface\AddOns\AmdirMusicLibrary`, тож оновлення
аддона через Amdir AddOns Downloader її **не видаляє**.

1. Запустіть `UpdatePlaylist.bat` у папці `Interface\AddOns\AmdirMusicPlayer`.
   Він створить папку `Interface\AddOns\AmdirMusicLibrary\Music` і відкриє її.
2. Покладіть туди MP3 / OGG (можна у підпапки — у плеєрі це будуть папки).
3. Ще раз запустіть `UpdatePlaylist.bat`.
4. **Повністю перезапустіть WoW** (`/reload` нових файлів не бачить).

Linux / Wine: `bash UpdatePlaylist.sh` (потрібен лише Python 3).

## Команди

`/music` (або `/mp`) — відкрити вікно, `/music play`, `/music stop`, `/music next`,
`/music prev`, `/music shuffle`, `/music list`, `/music root`, `/music up`,
`/music minimap` — сховати/показати кнопку на мінімапі, `/music 5` — грати трек №5.

## Обмеження клієнта 3.3.5a

- Окремий звук зупинити неможливо, тому «Стоп» і перемикання треку коротко перезапускають
  звукову систему гри: на мить обриваються всі звуки, можливе невелике підвисання.
  Коли трек закінчується сам, наступний вмикається без перезапуску.
- Перемотування й пауза недоступні; час на смузі прогресу розрахунковий.
- Поки грає плеєр, його повзунок змінює «Загальну гучність», а «Звук», «Музика» і «Світ»
  підлаштовуються. Після «Стоп» усе повертається.
